সদকায়ে জারিয়া কল্যাণ ফাউন্ডেশন — বিনামূল্যের ওয়েবসাইট

ফাইল:
- index.html : সম্পূর্ণ ওয়েবসাইট। মোবাইল ও কম্পিউটার-উপযোগী।
- README.txt : প্রকাশ করার নির্দেশনা।

GitHub Pages-এ বিনামূল্যে প্রকাশ:
1. https://github.com এ গিয়ে বিনামূল্যে অ্যাকাউন্ট খুলুন/সাইন ইন করুন।
2. New repository তৈরি করুন। নাম দিন: sadakaye-jaria-foundation
3. Repository-টি Public রাখুন (GitHub Free-তে Pages-এর জন্য public repository দরকার)।
4. Add file → Upload files নির্বাচন করে এই ZIP-এর ভেতরের index.html ফাইলটি আপলোড করুন। README চাইলে সেটিও আপলোড করতে পারেন।
5. Commit changes চাপুন।
6. Repository-র Settings → Pages-এ যান।
7. Build and deployment অংশে Deploy from a branch নির্বাচন করুন; Branch: main এবং folder: /(root) দিয়ে Save করুন।
8. কিছুক্ষণ পরে Pages অংশে প্রকাশিত ওয়েবসাইটের URL দেখাবে। সাধারণত URL হবে:
   https://YOUR-USERNAME.github.io/sadakaye-jaria-foundation/
   YOUR-USERNAME-এর জায়গায় আপনার GitHub username বসবে।
9. URL না এলে 5–10 মিনিট অপেক্ষা করে Settings → Pages আবার দেখুন।

গুরুত্বপূর্ণ:
- এই ZIP নিজে থেকে লাইভ ওয়েবসাইট তৈরি করে না; GitHub Pages-এ আপলোড ও প্রকাশ করতে হবে।
- এই সাইটটি তথ্য দেখানোর static website। এটি নিজে থেকে অনুদান গ্রহণ, অনলাইন লগইন বা স্বয়ংক্রিয় হিসাবের database চালায় না।
- ঠিকানা, ফোন, ছবি ও অনুদান গ্রহণের তথ্য যোগ করার আগে ফাউন্ডেশনের অনুমোদন নিন।
- মাসে ৮৫ টাকা হলে বছরে ১,০২০ টাকা হয়; বার্ষিক ১,০০০ টাকার প্রস্তাবটি সদস্যদের আলোচনায় চূড়ান্ত করুন।
